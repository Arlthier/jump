## Commits tags
|Tag|Uso|
|---|---|
|`feat:`|Nova funcionalidade|
|`fix:`|Correção de bug|
|`refactor:`|Reestruturação sem alterar comportamento|
|`docs:`|Documentação|
|`test:`|Adição ou alteração de testes|
|`chore:`|Tarefas de manutenção|
|`perf:`|Otimização de performance|
|`style:`|Formatação e estilo de código|
|`build:`|Alterações de build, dependências ou pipeline|
|`ci:`|Integração contínua e automações|

| Tag        | Uso                       |
| ---------- | ------------------------- |
| `art:`     | Assets visuais            |
| `audio:`   | Sons e música             |
| `level:`   | Fases e mapas             |
| `balance:` | Balanceamento de gameplay |
| `ui:`      | Interface                 |
| `tools:`   | Ferramentas internas      |
